Windows 构建（Python 3.12，干净虚拟环境）

python -m pip install --require-hashes --only-binary=:all: -r requirements-build-windows.lock
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean --onefile --windowed --name YoutubeDLT --collect-all PyQt6 --hidden-import PyQt6.QtCore --hidden-import PyQt6.QtGui --hidden-import PyQt6.QtWidgets --exclude-module yt_dlp --hidden-import certifi main.py

输出：dist/YoutubeDLT.exe。Windows 构建 PATH 仅保留当前 Python、Scripts 和 Windows 系统目录，详见 CI 工作流，避免收集其他工具的 DLL。
yt-dlp 由界面单独安装和更新，不要再打包旧的 yt_dlp Python 模块。
FFmpeg/ffprobe 由用户维护最新版，可放在 PATH 或程序旁；默认构建不嵌入未经核实的本机 FFmpeg。
macOS 构建以 .github/workflows/release.yml 为准；Windows 锁文件不能作为 macOS 锁文件使用。
